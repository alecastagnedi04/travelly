# Travelly
Travelly è un'applicazione web dedicata alla pianificazione e alla gestione di viaggi e itinerari.

## Funzionalità principali
- Registrazione e autenticazione degli utenti
- Creazione e gestione dei viaggi
- Gestione di destinazioni e attività
- Gestione dei partecipanti
- Registrazione e ripartizione delle spese
- Dashboard interattiva sviluppata con React
- Gestione di itinerari pubblici e privati
- Gestione dei template di viaggio
